# 試行錯誤ログ (Jekyll Blog)

このリポジトリは、Jekyllと[Chirpyテーマ](https://github.com/cotes2020/jekyll-theme-chirpy)を使用して構築された技術ブログのソースコードです。
変更を `main` ブランチにプッシュするだけで、GitHub Actions経由で自動的にGitHub Pagesへデプロイ（公開）されます。

## 📝 記事の書き方

新しい記事を追加するには、`_posts/` フォルダの中にMarkdownファイルを作成します。

### 1. ファイル名のルール
ファイル名は必ず **`年-月-日-英語のタイトル.md`** という形式にしてください。（例: `2026-10-03-go-concurrency-memo.md`）
※このファイル名がそのまま記事のURLになるため、英語やローマ字推奨です。

### 2. ファイルの先頭（Front Matter）の設定
作成したファイルの先頭に、以下の設定（Front Matter）を必ず記述してから本文を書き始めてください。

```yaml
---
layout: post
title: "記事のタイトルをここに書く"
date: 2026-10-03 12:00:00 +0900
categories: [大カテゴリ, 小カテゴリ]
tags: [タグ1, タグ2, タグ3]
---

ここからマークダウンで本文を書き始めます...
```

*   `categories`: 最大2つまで指定可能です。
*   `tags`: 記事に関連するキーワードを複数指定できます（小文字推奨）。

## 🚀 公開方法

記事を書き終えたら、通常通りGitでコミットし、プッシュするだけで自動的に公開されます。

```bash
git add .
git commit -m "feat(post): 新しい記事を追加"
git push
```

プッシュ後、数分以内にGitHub Actionsがビルドを行い、サイトが更新されます。

## ⚙️ ブログの設定変更

ブログの各種設定は以下のファイルを編集することで変更できます。

*   **ブログ名や基本設定**: `_config.yml` （タイトル、説明、アバター画像など）
*   **サイドバー下部のSNSアイコン**: `_data/contact.yml`
*   **日本語の文言調整**: `_data/locales/ja-JP.yml` （「投稿者」の非表示などを設定済み）
